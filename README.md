# 🖼️ AI vs. Real Image Detection Game

An interactive web game built with **React**, **TypeScript**, and **Vite** for the **Web Programming** course, where players identify which image among candidates is AI-generated.

---

## Overview

Players choose a category and difficulty level, inspect the displayed candidate images, and submit their guess to determine whether an image was generated by AI (`isAi: true`) or is a real/non-AI image (`isAi: false`).

---

## Key Features

- **Categories:** `insan` (Human), `manzara` (Landscape), and `hayvan` (Animal) image sets.
- **Difficulty Levels:** `kolay` (Easy) and `zor` (Hard) modes with tailored datasets and hints.
- **Two-Attempt Gameplay & Hints:** Wrong first guesses eliminate the selected image and display a difficulty-based hint before the final attempt.
- **Multi-Screen Flow:** Dedicated screens for starting/configuring the game (`BaslangicEkrani`), playing (`OyunEkrani`), and viewing the outcome (`SonucEkrani`).

## Getting Started

### Prerequisites
- Node.js (npm)

### Run Locally
```bash

cd ai-vs-real-image-game
```
